# WaterFlow - ระบบจัดการร้านน้ำ & คำนวณต้นทุนกำไร

เว็บแอปพลิเคชันจัดการร้านน้ำและคำนวณต้นทุน สไตล์ UI แบบ **Fastwork** (Brand Blue #0050f0) พร้อมฟอนต์ **Sarabun (TH Sarabun)** รองรับการแสดงผลทั้งบนคอมพิวเตอร์และโทรศัพท์มือถือ (Responsive Mobile First) สามารถอัปโหลดและเปิดใช้งานผ่าน **GitHub Pages** ได้ทันทีโดยไม่ต้องติดตั้ง Backend หรือ Database เสริม

---

## 🌟 ฟังก์ชันการทำงานหลัก

### 1. แดชบอร์ดสรุปยอดขายตลอดเดือน
- **ยอดขายรวมตลอดเดือน** (Monthly Revenue)
- **ต้นทุนสินค้า & วัตถุดิบ** (Cost of Goods Sold)
- **หักค่าเช่าร้านอัตโนมัติ** 10,000 บาท/เดือน (สามารถปรับเปลี่ยนจำนวนได้ในหน้าตั้งค่า)
- **กำไรสุทธิคงเหลือ** (ยอดขาย - ต้นทุน - ค่าเช่าร้าน 10,000 บ.)
- กราฟแท่ง-เส้นแสดงแนวโน้มรายวัน และกราฟโดนัทสัดส่วนค่าใช้จ่าย

### 2. รายได้วันนี้ & บันทึกบิลขาย (Quick Tap POS)
- สรุปยอดขายวันนี้, ต้นทุนที่ขายไป, และกำไรเบื้องต้น
- ปุ่มคีย์ด่วนกดขายทันที (Quick POS Tap) สำหรับน้ำชงสด น้ำแยกขวด หรือน้ำแบบโหล
- ประวัติบิลขายประจำวัน สามารถเพิ่ม/แก้ไข/ลบรายการได้

### 3. บันทึกค่าใช้จ่าย & ต้นทุนวัตถุดิบ
- บันทึกค่าใช้จ่ายแยกหมวดหมู่:
  - วัตถุดิบเครื่องดื่ม (นมข้นหวาน, ชา, โกโก้, น้ำเชื่อม)
  - บรรจุภัณฑ์ (โหลแก้วบรรจุน้ำ, ขวด, แก้ว, ฝา, หลอด)
  - สินค้าซื้อยกลัง/สำเร็จรูป (น้ำแยกขวดพร้อมขาย)
  - ค่าใช้จ่ายอื่นๆ (น้ำแข็ง, อุปกรณ์ชง)

### 4. เครื่องคำนวณราคาขาย (เฉพาะน้ำขวด / ซื้อยกลัง)
- คำนวณต้นทุนต่อขวดเมื่อซื้อยกลังอัตโนมัติ เช่น ซื้อมา 1 ลัง 24 ขวด ราคา 349 บาท:
  - ต้นทุนตัวสินค้า = 349 ÷ 24 = 14.54 บาท/ขวด
  - บวกต้นทุนแฝง (ถุงหิ้ว, หลอด, แช่เย็น) เช่น +1.00 บาท = ต้นทุนรวมจริง 15.54 บาท
- กำหนด % กำไรที่ต้องการ (Margin) ระบบจะแนะนำราคาขายต่อขวดและคำนวณกำไรต่อขวด/กำไรต่อลังให้ทันที
- ตารางเปรียบเทียบราคาขายตัวเลือก (เช่น ตั้งราคา 20, 25, 30 บาท)

### 5. ปฏิทินสรุปยอดขายรายวันตลอดทั้งเดือน
- แสดงปฏิทินทั้งเดือนแบบ interactive
- แต่ละวันระบุยอดขายและกำไรชัดเจน
- คลิกที่ช่องวันที่เพื่อดูรายการบิลย้อนหลังและเพิ่มบิลให้วันนั้นได้

### 6. สูตรชงน้ำต่อ 1 โหล (Batch Recipes)
- จัดการสูตรชงน้ำสำหรับใส่โหลแก้ว/เหยือก (เช่น 5 ลิตร / 12 แก้ว)
- ระบุส่วนผสมและต้นทุนของแต่ละวัตถุดิบ
- คำนวณต้นทุนรวมต่อโหล, ต้นทุนเฉลี่ยต่อแก้ว, กำไรต่อแก้ว และกำไรต่อโหลอัตโนมัติ
- มีปุ่ม "ขายเมนูนี้" เชื่อมโยงเข้าสู่ระบบบันทึกการขายทันที

### 7. จัดการข้อมูล & สำรองข้อมูล
- บันทึกข้อมูลลง `LocalStorage` ของเบราว์เซอร์อัตโนมัติ ข้อมูลไม่หายเมื่อปิดหน้าเว็บ
- ปุ่มส่งออกไฟล์ (Export JSON Backup) สำหรับเก็บสำรองหรือย้ายเครื่อง
- ปุ่มนำเข้าไฟล์ (Import JSON) สำหรับกู้คืนข้อมูล

## 🚀 วิธีนำขึ้นใช้งานบน GitHub Pages (ฟรี 100%)

1. เข้าเว็บไซต์ [github.com](https://github.com/) และเข้าสู่ระบบ
2. กดสร้าง Repository ใหม่ (ชื่อ เช่น `water-shop` หรือ `water-pos`) และเลือกเป็น **Public**
3. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป (`index.html`, `style.css`, `app.js`, `README.md`)
4. ไปที่แท็บ **Settings** ของ Repository บน GitHub
5. เลือกเมนูด้านซ้าย **Pages**
6. ใต้หัวข้อ **Build and deployment**:
   - Source: เลือก **Deploy from a branch**
   - Branch: เลือก **main** (หรือ **master**) และเลือกโฟลเดอร์เป็น **/(root)**
   - กด **Save**
7. รอประมาณ 1-2 นาที คุณจะได้ URL เว็บไซต์ เช่น:
   ```
   https://<your-username>.github.io/<your-repository-name>/
   ```
   สามารถบันทึกเป็น Bookmark บนมือถือหรือหน้าจอโฮมเพื่อเปิดบันทึกยอดขายได้ตลอดเวลา
